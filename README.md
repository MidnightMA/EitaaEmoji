# 🎮 بازی حدس ایموجی (مینی‌اپ ایتا) - Eitaa Emoji Game

یک بازی تحت وب فوق‌العاده جذاب و بهینه‌شده برای پلتفرم **مینی‌اپ ایتا (Eitaa Web App)**. در این بازی کاربران باید با نگاه کردن به ترکیبی از ایموجی‌ها، ضرب‌المثل‌ها، نام فیلم‌ها یا کشورها را حدس بزنند. این پروژه با الهام از زبان طراحی **iOS اپل** ساخته شده و بدون استفاده از هیچ فریم‌ورکی، تنها با جاوااسکریپت خالص (Vanilla JS) توسعه یافته است.

---

## ✨ ویژگی‌های کلیدی

- ⚡ **فوق‌سبک و سریع:** بدون نیاز به React, Vue یا هیچ پکیج npm. کاملاً آماده برای اجرا روی هاست‌های استاتیک مثل GitHub Pages.
- 🍏 **ایموجی‌های اپل (Apple Emojis):** تبدیل خودکار ایموجی‌های سیستم به ایموجی‌های استاندارد و زیبای آیفون با سیستم Caching قدرتمند برای لود آنی.
- 🎨 **طراحی iOS:** رابط کاربری مدرن با افکت‌های Glassmorphism، گوشه‌های گرد استاندارد، فونت‌های بهینه و انیمیشن‌های نرم.
- ☁️ **ذخیره‌سازی ابری و هوشمند:** اتصال به دیتابیس خارجی (KVDB) بر اساس **ID ایتا** برای همگام‌سازی پیشرفت کاربر در دستگاه‌های مختلف، به همراه بک‌آپ آفلاین (LocalStorage).
- 🏆 **سیستم مدال‌ها و افتخارات:** باز شدن مدال‌های جدید (Achievements) با پیشروی در بازی به همراه اعلان‌های (Toast) جذاب.
- 🎵 **موتور صوتی داخلی:** تولید افکت‌های صوتی بازی با استفاده از ریاضیات و `Web Audio API` (بدون نیاز به آپلود فایل‌های mp3).
- 🌓 **پشتیبانی از حالت تاریک (Dark Mode):** سازگاری کامل با تم گوشی و قابلیت تنظیم دستی.
- 👤 **همگام با ایتا:** خواندن خودکار نام و **عکس پروفایل** کاربر به صورت مستقیم از SDK ایتا.

---

## 🛠 تکنولوژی‌های استفاده شده

- **HTML5 & CSS3** (طراحی ریسپانسیو و Mobile-first)
- **Vanilla JavaScript (ES6+)** (منطق بازی)
- **Eitaa Web App JS SDK** (ارتباط با پیام‌رسان ایتا)
- **Web Audio API** (صداگذاری)
- **KVDB.io / REST API** (دیتابیس ابری بدون نیاز به ثبت‌نام و فیلترشکن)

## 🚀 آموزش راه‌اندازی و نصب

از آنجایی که این پروژه کاملاً استاتیک است، نیازی به نصب هیچ پیش‌نیازی (مثل Node.js) ندارید!

### مرحله ۱: دریافت کدها
فایل‌های پروژه را دانلود کرده یا کلون کنید. شما تنها به ۴ فایل نیاز دارید: `index.html`، `style.css`، `app.js` و `data.json`.

### مرحله ۲: راه‌اندازی دیتابیس ابری (رایگان)
برای اینکه پیشرفت کاربران با عوض کردن گوشی از بین نرود:
1. وارد سایت [kvdb.io](https://kvdb.io) شوید (نیازی به ثبت‌نام نیست).
2. روی دکمه مشکی **Create Database** کلیک کنید.
3. یک شناسه یکتا (Bucket ID) به شما داده می‌شود. (مثلاً: `WjXyZk123EmojiGame`)
4. فایل `app.js` را باز کرده و در خط ۲۲، این شناسه را جایگزین کنید:
   ```javascript
   const KVDB_BUCKET_ID = "شناسه_دریافتی_شما"; 
   ```

### مرحله ۳: انتشار (Deployment)
کدهای خود را روی یک هاست استاتیک مثل **GitHub Pages**، **Vercel** یا **لیارا** آپلود کنید.
سپس لینک سایت خود را در ربات توسعه‌دهندگان ایتا ثبت کنید تا به عنوان مینی‌اپ اجرا شود.

## 📂 ساختار فایل‌ها

- 📄 `index.html`: اسکلت‌بندی اصلی صفحات (صفحه اصلی و صفحه بازی) و مودال‌ها.
- 🎨 `style.css`: استایل‌ها، انیمیشن‌های CSS و متغیرهای حالت تاریک/روشن.
- ⚙️ `app.js`: مغز متفکر بازی، سیستم سینک ابری، رندر ایموجی‌ها و مدیریت رویدادها.
- 🗄️ `data.json`: دیتابیس مراحل بازی که به راحتی قابل توسعه است.

---

## 🧩 نحوه افزودن مراحل جدید

برای اضافه کردن مراحل یا دسته‌بندی‌های جدید، کافیست فایل `data.json` را ویرایش کنید. ساختار آن بسیار ساده است:

```json
{
  "categories": [
    {
      "id": "proverbs",
      "name": "ضرب‌المثل‌ها",
      "icon": "🎭",
      "levels": [
        { "emoji": "👂🏻🚪👂🏻🥅", "answer": "یه گوشش دره یه گوشش دروازه" },
        { "emoji": "🐓🦵1️⃣", "answer": "مرغ یه پا داره" }
      ]
    }
  ]
}
```

**نکته:** سیستم به صورت خودکار ایموجی‌های وارد شده را به شکل ایموجی‌های آیفون در می‌آورد و کلیدهای کیبورد را بر اساس حروف پاسخ شما به صورت رندوم تولید می‌کند.
